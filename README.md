## 📖 项目简介

Node.js 是一个开源、跨平台的 JavaScript 运行时环境,基于 Chrome 的 V8 引擎构建,让 JavaScript 能够脱离浏览器在服务端、桌面与嵌入式设备上运行。项目采用开放治理模式,由 OpenJS 基金会提供支持,是全球最大的开源项目之一,也是前后端全栈开发的基石。

## ✨ 主要特性

- ⚡ **V8 引擎驱动**:直接编译执行 JavaScript,高性能非阻塞 I/O
- 🔄 **双轨发布**:Current 版本 6 个月一轮快速迭代,偶数版本转 LTS 长期支持
- 🛡️ **LTS 保障**:12 个月 Active LTS + 18 个月维护期,生产环境无忧
- 🌙 **Nightly 构建**:每日构建供尝鲜与测试
- 🔐 **可验证二进制**:官方发布均带签名,可本地校验
- 🏛️ **开放治理**:TSC 技术指导委员会 + 协作者 + 分诊员的多层社区治理
- 📦 **海量生态**:npm 生态数百万包,Web 服务、CLI、构建工具通吃

## 🚀 快速开始

完整源代码请访问原项目:https://github.com/nodejs/node

1. 访问 [Node.js 官网](https://nodejs.org) 下载安装包(LTS 或 Current)
2. 验证安装:

```bash
node -v
npm -v
```

3. 运行第一个程序 `hello.js`:

```javascript
console.log("你好,Node.js!");
```

```bash
node hello.js
```

4. 从源码构建(可选):

```bash
./configure
make -j4
make install
```
